C4AG1WP0Dépose - repose : Capot moteur et bras d’articulation
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Opérations préliminaires
Déposer :
  • Le pare-chocs avant (voir opération correspondante)
  • Les projecteurs(voir opération correspondante)
  • Les pare-boue (voir opération correspondante)
  • Les ailes avant(voir opération correspondante)
2. Dépose
Figure : c4ap1hbd
Désaccoupler le tuyau lave-vitre ( 1).
Déposer :
  • Les vis (2)
  • Le capot
NOTA : Pour l’opération de dépose 2 opérateurs sont nécessaires.
3. Déshabillage
Figure : c4ap1hcd
Déposer :
  • Les gicleurs de lave-vitre ( 7)
  • Les butées caoutchouc (6)
  • Les agrafes (8)
  • La garniture de capot (3)
  • Les agrafes (5)
  • L’enjoliveur de capot (4)
4. Repose - Habillage
4.1. Pose et habillage du capot moteur
Procéder dans l’ordre inverse des opérations de dépose.
ATTENTION : Respecter les jeux et affleurements.
4.2. Pose de l’enjoliveur de capot
Nettoyer la zone d’application à l’aide d’un produit ( J1).
Amener la température de la zone d’application à 20°C.
Enlever le papier protecteur de l’enjoliveur de capot.
Présenter les tétons de l’enjoliveur de capot ( 4) en face des perçages de positionnement.
Appliquer l’enjoliveur sur le capot.
Appuyer fortement sur l’enjoliveur de capot du milieu vers les extrémités à l’aide d’un chiffon propre (5 secondes minimum).
Poser les agrafes ( 5) des extrémités vers le milieu de l’enjoliveur de capot.
