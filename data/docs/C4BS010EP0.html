C4BS010EP0Déshabillage - Habillage : Volet arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage préconisé
Figure : e5ap1gkc
[1] Extracteur de bras d’essuie-vitre  (type FACOM U.14A).
Figure : e5am0b3d
[2] Pince pour dépose des pions plastique 7504-T.
2. Déshabillage
Figure : c4bm167d
Légende :
  • Déflecteur de volet arrière (1)
  • Bras balai d’essuie-vitre (2)
  • Poignée d’ouverture de volet (3)
Déposer le bras balai d’essuie-vitre (2) ; À l’aide de l’outil [1].
Figure : c4bm168d
Déposer les vis (6).
Déclipper ; À l’aide de l’outil [2] :
  • Les garnitures latérales de volet (4)
  • La garniture inférieure de volet (5)
Figure : c4bm169d
Déposer vis (8) (de chaque côté).
Déclipper : La garniture supérieure d’entrée de volet (7) ; À l’aide de l’outil [2].
Figure : c4bm16ad
Déconnecter :
  • Le connecteur "/"  (essuie-vitre arrière) (en "a")
  • Le connecteur de la serrure (en "b")
  • Le connecteur "/"  (vitre chauffante) (en "c")
Déposer :
  • Les vis (9)
  • Le déflecteur de volet (1)
  • Les vis (14)
  • La serrure (13)
  • Poignée d’ouverture de volet (3)
  • Le faisceau électrique (10)
Percer les rivets (11) ; À l’aide d’un foret Ø 8 mm.
Déposer :
  • Le moteur d’essuie-vitre (12)
  • La vitre de volet arrière  (voir opération correspondante)
  • Les clips de maintien (15) de l’enjoliveur de volet
Décoller :
  • Les monogrammes
  • L’enjoliveur de volet
3. Habillage
Couple de serrage :
  • Vis de serrure : 0,8 ± 0,1 m.daN
  • Écrou de fixation du bras d’essuie-vitre : 1,2 ± 0,1 m.daN
Procéder dans l’ordre inverse des opérations de déshabillage.
Figure : c4bm16bd
NOTA : L’enjoliveur de volet et les monogrammes ne sont pas récupérables et doivent être remplacés lorsqu’ils sont déposés.
Reposer :
  • L’enjoliveur de volet
  • Les monogrammes "A", "B", "C", "D" (Respecter les cotes suivantes)
"A" = 600 mm.
"B" = 45 mm.
"C" = 175 mm.
"D" = 190 mm.
Vérifier le fonctionnement des éléments déposés.
