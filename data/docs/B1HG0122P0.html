2. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI).
Débrancher la borne négative de la batterie.
Figure : b1bm0c1d
Déposer :
  • Le cache-style
  • Les fixations (1)
Écarter la barrette porte faisceau électrique (2).
Désaccoupler et écarter la durit (7).
Désaccoupler et obturer : Les raccords basse pression carburant (3), (4, (5), (6) ; À l’aide des outils [5].
Figure : b1bm0c2d
ATTENTION : Nettoyer les raccords haute pression avant desserrage.
Desserrer :
  • Le raccord (10) : Appliquer un contre-couple (en "a")
  • Le raccord (9)
Déposer le tube d’alimentation haute pression (8).
Figure : b1bm0c3d
Desserrer :
  • Les raccords sur les injecteurs diesel : Appliquer un contre-couple (en "b")
  • Les raccords des tubes sur la rampe d’injection commune haute pression carburant
Déposer les tubes d’alimentation haute pression .
ATTENTION : Obturer les raccords sur les injecteurs diesel et sur la rampe d’injection commune haute pression carburant ; À l’aide des outils [5].
Figure : b1hm09ld
Déconnecter :
  • Le capteur haute pression carburant (14)
  • La sonde de température carburant (13)
Déposer :
  • Les vis (11)
  • La rampe d’injection commune haute pression carburant (12)
3. Repose
ATTENTION : Remplacer le ou les tubes haute pression d’injection diesel déposés.
Reposer :
  • La rampe d’injection commune haute pression carburant (12)
  • Les vis (11) (serrer à la main)
  • Le tube (8) (neuf)
Méthode de serrage ( tube (8)) :
  • Préserrer le raccord (10) à 0,8 ± 0,2 m.daN : Appliquer un contre-couple (en "a")
  • Préserrer le raccord (9) à 2,4 ± 0,6 m.daN
  • Serrer le raccord (10) à 2,6 ± 0,26 m.daN : Appliquer un contre-couple (en "a")
  • Serrer le raccord (9) à 2,6 ± 0,26 m.daN
Reposer les tubes d’alimentation haute pression des injecteurs diesel comme suit :
  • Monter les tubes des injecteurs diesel pour les cylindres 2 et 4
  • Serrer à fond de filet et à la main les raccords sur les injecteurs diesel et sur la rampe commune haute pression carburant
  • Monter les tubes des injecteurs diesel pour les cylindres 1 et 3
  • Serrer à fond de filet et à la main les raccords sur les injecteurs diesel et sur la rampe commune haute pression carburant
ATTENTION : Clipper les agrafes sur les tubes en respectant le même emplacement. Ne pas utiliser d’outil (exemple : pince multiprise ...) ; Desserrer au besoin les raccords pour faciliter la mise en place des agrafes puis les serrer à la main.
Serrer les vis (11) à 2,25 ± 0,2 m.daN .
Figure : b1bm0c4d
Appliquer un contre-couple (en "b").
Serrer les raccords sur les injecteurs diesel à 2,05 ± 0,2 m.daN ; À l’aide des outils [1], [2], [3].
Figure : b1bm0c5d
Serrer les raccords sur la rampe d’injection commune haute pression carburant à 2,05 ± 0,2 m.daN ; À l’aide des outils [1], [2], [3].
Connecter :
  • Le capteur haute pression carburant (14)
  • La sonde de température carburant (13)
Déposer les outils [5].
Accoupler : Les raccords basse pression carburant (3), (4, (5), (6).
Reposer :
  • La durit (7)
  • La barrette porte faisceau électrique (2)
  • Les fixations (1)
Rebrancher la borne négative de la batterie.
4. Contrôle d’étanchéité
ATTENTION : Pulvériser le produit [4] sur les raccords injecteurs diesel et sur la rampe d’injection commune haute pression carburant .
Méthode de contrôle :
  • Laisser sécher le produit
  • Démarrer le moteur
  • Vérifier l’absence de fuite
  • Accélérer jusqu’à un régime de 4000 tr/mn
  • Vérifier l’absence de fuite
  • Faire un essai routier
  • Vérifier l’absence de fuite
  • Remplacer les pièces défectueuses (si nécessaire)
Reposer le cache-style.
