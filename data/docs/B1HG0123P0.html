2. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI).
Débrancher la batterie .
Déposer :
  • La courroie d’entraînement des accessoires
  • La courroie de distribution
ATTENTION : Reposer le support moteur droit .
Figure : b1bm0c6d
Déconnecter le connecteur (1).
Écarter :
  • La durit (2)
  • La durit (3)
Figure : b1bm0c7d
ATTENTION : Nettoyer : Les raccords carburant (Lors de chaque dépose).
Désaccoupler :
  • Le raccord d’alimentation basse pression carburant (4)
  • Le raccord de retour basse pression carburant (7)
ATTENTION : Appliquer un contre-couple (en "a").
Déposer :
  • Le tube haute pression carburant (5)
  • La fixation arrière (6)
ATTENTION : Obturer les orifices de la pompe haute pression ; À l’aide des outils [7].
Figure : b1bm0c8d
Poser l’outil [5].
Desserrer puis déposer le pignon (8) d’entraînement de pompe haute pression ; À l’aide de l’outil [4].
Figure : b1bm0c9d
Déposer :
  • Les vis (9)
  • La pompe haute pression carburant
3. Repose
ATTENTION : Remplacer le ou les tubes haute pression déposés .
Reposer :
  • La pompe haute pression carburant
  • Les vis (9) ; Serrer à 2 ± 0,2 m.daN
  • Le pignon (8) ; À l’aide de l’outil [4]; Serrage à 5 ± 0,5 m.daN
Figure : b1bm0cad
Méthode de serrage : Tube haute pression carburant (5) :
  • Préserrer le raccord (10) à 0,8 ± 0,2 m.daN ; Appliquer un contre-couple (en "a")
  • Préserrer le raccord (11) à 2,4 ± 0,6 m.daN
  • Serrer le raccord (10) à 2,6 ± 0,26 m.daN ; Appliquer un contre-couple (en "a")
  • Serrer le raccord (11) à 2,6 ± 0,26 m.daN
Reposer : La fixation arrière (6) ; Serrage à 2,25 ± 0,2 m.daN.
Accoupler :
  • Le raccord de retour basse pression carburant (7)
  • Le raccord d’alimentation basse pression carburant (4)
Connecter le connecteur (1).
Reposer :
  • La courroie de distribution
  • La courroie d’entraînement des accessoires
Rebrancher la batterie.
4. Contrôle d’étanchéité
ATTENTION : Pulvériser le produit [6] sur le raccord du tuyau haute pression (5).
Laisser sécher le produit.
Démarrer le moteur.
Vérifier l’absence de fuites.
Accélérer jusqu’à un régime de 4000 tr/mn.
Vérifier l’absence de fuites.
Faire un essai routier.
Vérifier l’absence de fuites.
Remplacer les pièces défectueuses (si nécessaire).
