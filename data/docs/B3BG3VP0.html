B3BG3VP0Dépose - repose : Élément de suspension avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : b3ep00cc
[1] extracteur de rotule 1892-T.
2. Dépose
Lever et caler le véhicule, roues avant pendantes.
Déposer les roues avant.
Figure : b3bp19fc
Déposer l’écrou (1).
Écarter la biellette de barre antidévers.
Déposer l’écrou (2).
Désaccoupler la rotule de direction à l’aide de l’extracteur [1].
Déposer les vis (3) (fixation de l’élément de suspension sur le pivot).
IMPERATIF : Placer une protection sur le soufflet de transmission.
Figure : c4ap1f2c
Déposer :
  • Les bras d’essuie-vitre (4) (voir opération correspondante)
  • La grille d’auvent (5) (voir opération correspondante)
Figure : c4ap1f3c
ATTENTION : Lors du dégagement de l’élément de suspension, maintenir la transmission dans le différentiel.
Déposer :
  • L’écrou (6)
  • La coupelle (7)
  • L’élément de suspension
3. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Train avant
  • Roue
ATTENTION : Remplacer systématiquement les écrous Nylstop.
Figure : c4ap1f4d
Positionner les bossages en "a" du support d’amortisseur dans les emboutis en "b" du passage de roue.
Engager l’élément de suspension dans le passage de roue.
Reposer :
  • La coupelle (7)
  • L’écrou (6)
Positionner le pivot dans la pince de l’élément de suspension.
Reposer les vis (3).
Accoupler la rotule de direction sur le pivot.
Reposer l’écrou (2).
Positionner la biellette de barre antidévers avant sur l’élément de suspension.
Reposer l’écrou (1).
Reposer :
  • La grille d’auvent (5) (voir opération correspondante)
  • Les bras d’essuie-vitre (4) (voir opération correspondante)
  • Les roues avant
Replacer le véhicule sur le sol.
Serrer les vis de roue.
Contrôler et régler le parallélisme.
