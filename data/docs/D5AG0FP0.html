(1) : Autoradio.
(2) : Lecteur CD (suivant option).
"a" et "b" : Orifice pour passage des épingles [1294].
2.1. Dépose de l’autoradio
Insérer les épingles [1294] dans les orifices "a" jusqu’au clippage.
Extraire l’autoradio (1) à l’aide des épingles [1294].
Déconnecter l’autoradio (1).
Déposer l’autoradio (1).
Déclipper les épingles [1294] de l’autoradio.
2.2. Dépose du lecteur CD (suivant option)
Insérer les épingles [1294] dans les orifices "b" jusqu’au clippage.
Extraire le lecteur CD (2) à l’aide des épingles [1294].
Déconnecter le lecteur CD (2).
Déposer le lecteur CD (2).
Déclipper les épingles [1294] du lecteur CD.
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Brancher la batterie.
Vérifier le fonctionnement des équipements.
