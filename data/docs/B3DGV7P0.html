2. Dépose
Déposer le train arrière .
Figure : b3dp0d5d
Déposer :
  • La vis (1)
  • La chape ( 2)
Figure : b3dp0d6d
Repérer le positionnement de l’articulation élastique ( 3) par rapport au bras de suspension à l’aide d’un trait (en "a").
Figure : b3dp0d7d
Monter l’outil [ 2] sur le moyeu de l’articulation élastique (3).
Figure : b3dp0d8d
NOTA : Vérifier que la vis de l’outil [ 4] est bien graissée.
Monter les outils [ 3 - 4] sur l’articulation élastique (3).
Extraire l’articulation élastique ( 3) en vissant la vis de l’outil [4].
Déposer les outils [2], [3], [4].
3. Repose
ATTENTION : Respecter le positionnement des articulations élastiques ( 3).
Figure : b3dp0d9d
Monter l’outil [ 2] sur le moyeu de l’articulation élastique (3)  (à l’inverse de la dépose).
Figure : b3dp0dad
Positionner l’articulation élastique ( 3)  (respecter les repères lors de la dépose).
Monter :
  • L’articulation élastique (3)
  • Les outils [1], [4]
NOTA : Vérifier que la vis de l’outil [ 4] est bien graissée.
Serrer la vis de l’outil [ 4] jusqu’à la mise en place de l’articulation élastique (3).
Déposer les outils [ 1 - 2 - 4].
Reposer :
  • La chape ( 2)
  • La vis (1)  (sans serrer)
  • Le train arrière
