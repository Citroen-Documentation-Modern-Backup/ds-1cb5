C5DG0SP0Reconversion : Véhicule auto-école en véhicule particulier
DEPUIS OPR 10312
NOTA : Il est possible de déséquiper un véhicule auto-école sans déposer la planche de bord.
1. Opérations à réaliser
Déposer :
  • Le vide-poches avec le boîtier de commande moniteur
  • Le pédalier double-commande
  • Les barres de renvoi
  • La pédale d’accélérateur côté conducteur
  • Le pédalier côté conducteur
  • L’étiquette constructeur complémentaire "auto-école"
  • Le rétroviseur extérieur additionnel côté passager
  • Le rétroviseur intérieur additionnel auto-école et son support
Reposer :
  • Un pédalier d’origine côté conducteur
  • Une pédale d’accélérateur avec fonction LVV *
  • Un vide-poches d’origine
NOTA : * LVV : Limitation de vitesse véhicule.
Télécoder le boîtier de servitude intelligent (BSI).

Reposer un vide-poches d’origine.
1.8. Désinstallation du "module auto-école" à l’aide de l’outil de diagnostic : Procédure de désinstallation du "module auto-école" à l’aide de l’outil de diagnostic "LEXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "DIAGNOSTIC"
  • Sélectionner le véhicule "CITROËN C4"
  • "ÉQUIPEMENTS"
  • "MODULE AUTO-ÉCOLE"
  • Mettre le contact
  • "DÉSINSTALLATION"
Suivre les instructions données par l’outil de diagnostic.
ATTENTION : Si le module auto-école n’est pas accessible dans le menu de désinstallation d’un équipement, utiliser la procédure de télécodage du boîtier de servitude intelligent à l’aide de l’outil de diagnostic.
1.9. Désinstallation du "module auto-école" à l’aide de l’outil de diagnostic : Procédure de télécodage (À l’aide de l’outil de diagnostic "LEXIA")
ATTENTION : Cette procédure de télécodage du boîtier de servitude intelligent n’est à utiliser que dans le cas où le module auto-école est absent du menu de désinstallation d’un équipement.
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • Sélectionner le menu "Diagnostic"
  • Sélectionner le véhicule "CITROËN C4"
  • Saisir le numéro OPR
  • Sélectionner le menu "Test Global"
  • Mettre le contact
  • Sélectionner le calculateur boîtier de servitude intelligent "BSI"
  • Sélectionner le menu "TÉLÉCODAGE"
  • Sélectionner le menu "TÉLÉCODAGE MANUEL"
  • Sélectionner le menu "CONFIGURATION"
  • Sélectionner le menu  "DÉFINITION DU VÉHICULE - ÉQUIPEMENTS - INFORMATIONS CONDUITE"
  • Télécoder le paramètre "option auto-école" à la valeur "Absente"
  • Télécoder le paramètre "Présence et type de régulation de vitesse véhicule" à "Régulation et limitation de vitesse"
  • Appuyer sur la touche (F1) pour effectuer le télécodage
  • Renseigner le code d’accès
  • L’outil de diagnostic confirme que le télécodage des options de configuration s’est bien effectué
  • Appuyer sur la touche retour (F9)
  • Appuyer sur la touche retour (F9)
  • Sélectionner le menu "CALCULATEURS PRÉSENTS"
  • Télécoder le paramètre "module auto-école" à la valeur "absent"
  • Appuyer sur la touche (F1) pour effectuer le télécodage
  • Renseigner le code d’accès
  • L’outil de diagnostic confirme que le télécodage des calculateurs présents s’est bien effectué
  • Retourner dans le test global
  • Sélectionner le calculateur d’injection
  • Sélectionner le menu correspondant au calculateur d’injection du véhicule
  • Contrôler dans le télécodage les paramètres concernant la limitation de vitesse
  • Configurer ces paramètres afin d’activer la limitation de vitesse
  • Valider les modifications effectuées dans le télécodage
  • Appuyer sur la touche retour (F9) pour quitter
1.10. Désinstallation du "module auto-école" à l’aide de l’outil de diagnostic : Procédure de désinstallation du "module auto-école" à l’aide de l’outil de diagnostic "PROXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • "TÉLÉCHARGEMENT/TÉLÉCODAGE"
  • "INSTALLATION/DÉSINSTALLATION"
  • Sélectionner le véhicule "CITROËN C4"
  • Saisir le numéro OPR
  • "MODULE AUTO-ÉCOLE"
  • "DÉSINSTALLATION D’UN ÉQUIPEMENT"
Suivre les instructions données par l’outil de diagnostic.
ATTENTION : Si le module auto-école n’est pas accessible dans le menu de désinstallation d’un équipement, utiliser la procédure de télécodage du boîtier de servitude intelligent à l’aide de l’outil de diagnostic.
1.11. Désinstallation du "module auto-école" à l’aide de l’outil de diagnostic : Procédure de télécodage À l’aide de l’outil de diagnostic "PROXIA"
ATTENTION : Cette procédure de télécodage du boîtier de servitude intelligent n’est à utiliser que dans le cas où le module auto-école est absent du menu de désinstallation d’un équipement.
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • Sélectionner le menu "TÉLÉCHARGEMENT/ TÉLÉCODAGE"
  • Sélectionner le menu "TÉLÉCODAGE"
  • Sélectionner le véhicule "CITROËN C4"
  • Saisir le numéro OPR
  • Sélectionner le calculateur boîtier de servitude intelligent "BSI"
  • Mettre le contact
  • Sélectionner le menu "TÉLÉCODAGE MANUEL"
  • Sélectionner le menu "CONFIGURATION"
  • Sélectionner le menu  "DÉFINITION DU VÉHICULE - ÉQUIPEMENTS - INFORMATIONS CONDUITE"
  • Télécoder le paramètre "option auto-école" à la valeur "Absente"
  • Télécoder le paramètre "Présence et type de régulation de vitesse véhicule" à "Régulation et limitation de vitesse"
  • Appuyer sur la touche (F5) pour effectuer le télécodage
  • Saisir le code Après-vente
  • Appuyer sur la touche retour (F1)
  • Sélectionner le menu "MOTOPROPULSEUR"
  • Sélectionner le menu correspondant au calculateur d’injection du véhicule
  • Contrôler dans le télécodage les paramètres concernant la limitation de vitesse
  • Configurer ces paramètres afin d’activer la limitation de vitesse
  • Appuyer sur la touche retour (F1)
  • Appuyer sur la touche retour (F1)
  • Sélectionner le menu "CALCULATEURS PRÉSENTS"
  • Télécoder le paramètre "module auto-école" à absent (retirer la croix en face du paramètre)
  • Appuyer sur la touche (F5) pour effectuer le télécodage
  • Appuyer sur la touche (F1) pour quitter
