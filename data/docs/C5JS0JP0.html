C5JS0JP0Déshabillage - habillage : Pare-chocs arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap1gmc
[ 1] outil de démontage baguettes latérales 8205-T.E.
2. Opération préliminaire
Dépose - repose du pare-chocs arrière(voir opération correspondante).
3. Déshabillage
Figure : c5jp0c0d
Déconnecter les connecteurs des capteurs de proximité en " 1".
Déconnecter les éclaireurs de coffre ( 3).
Déposer le faisceau électrique (2).
Déclipper :
  • Les capteurs de proximité ( 1)
  • Les éclaireurs de coffre (3)
Déclipper en "a" :
  • Le bandeau de protection gauche
  • Le bandeau de protection droit
  • Le bandeau de protection central
4. Habillage
Clipper :
  • Le bandeau de protection gauche
  • Le bandeau de protection droit
  • Le bandeau de protection central
Reposer :
  • Les capteurs de proximité ( 1)
  • Les éclaireurs de plaque de police
  • Le faisceau électrique (2)
Connecter :
  • Les connecteurs d’éclaireurs de coffre
  • Les connecteurs des capteurs de proximité
