2. Coussinets de palier
2.1. Identification : Marquage / Carter-cylindres - Marquage / Vilebrequin
Figure : b1dp1u0d
Zone de marquage "a" :
  • lettres repère de code (5 lettres permettent l’identification des coussinets à monter)
  • La première lettre correspond au palier N°1
  • La flèche indique le côté distribution
2.2. Appariement des demi-coussinets de paliers de vilebrequin
Figure : b1dp1u1d
classe A : Repère bleu.
classe B : Repère de couleur orange.
classe C : Repère noir.
classe D : Repère couleur jaune.
classe E : Repère vert.
classe G : Repère blanc.
Choix des demi-coussinets (exemple) :
  • Demi-coussinets côté chapeaux de paliers : Si la première lettre du vilebrequin est (S) et celle du carter-cylindres (E), le demi-coussinet N° 1 doit être de classe (B) (Couleur orange)
  • Demi-coussinets côté carter-cylindres : Le demi-coussinet est toujours de classe "C" (Couleur noire)
