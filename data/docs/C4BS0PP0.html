C4BS0PP0Déshabillage - Habillage : Hayon
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap1gkc
[ 1] Extracteur de bras d’essuie-vitre (type FACOM U.14A).
Figure : e5-p14uc
[ 2] Pince pour dépose des pions plastique 7504-T.
2. Déshabillage
Figure : c4bp1h3c
Légende :
  • Déflecteur de hayon ( 1)
  • Bras balai d’essuie-vitre (2)
  • Poignée d’ouverture de hayon (3)
Déposer le bras balai d’essuie-vitre ( 2) À l’aide de l’outil [1].
Figure : c4bp1h4c
Déposer les vis (6).
Déclipper À l’aide de l’outil [2] :
  • Les garnitures latérales de hayon (4)
  • La garniture inférieure de hayon (5)
Figure : c4bp1h5c
Déposer vis (8) (de chaque côté).
Déclipper la garniture supérieure de hayon ( 7) À l’aide de l’outil [2].
Figure : c4bp1h6c
Déconnecter :
  • Le connecteur "a" (essuie-vitre arrière)
  • Le connecteur "b" (serrure)
  • Le connecteur "c" (vitre chauffante)
Déposer :
  • Les vis (9)
  • Le déflecteur de hayon (1)
  • Les vis (14)
  • La serrure (13)
  • Poignée d’ouverture de hayon (3)
  • Le faisceau électrique (10)
Percer les rivets ( 11) à l’aide d’un foret Ø 8 mm.
Déposer :
  • Le moteur d’essuie-vitre (12)
  • La vitre de hayon (voir opération correspondante)
3. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
