2. Présentation
La boîte de vitesses manuelle pilotée type MCP intègre un calculateur spécifique et un dispositif de pilotage par actionneurs de type S-CAM électrohydraulique MAGNETI MARELLI.
Le calculateur spécifique associé au dispositif de pilotage effectue les fonctions suivantes :
  • Commande de l’embrayage
  • Sélection et passage des rapports
Le conducteur change de rapport sans effort, la pédale d’embrayage est supprimée.
La boîte de vitesses manuelle pilotée type MCP a 2 programmes de fonctionnement :
  • Un programme "impulsionnel" : Le conducteur décide le changement de rapport de vitesses
  • Un programme "automatique" : Le calculateur de boîte de vitesses décide le changement de rapport de vitesses
Le démarrage du moteur thermique est autorisé en appuyant sur la pédale de frein.
2.1. Généralités
La boîte de vitesses manuelle pilotée type MCP est une nouvelle boîte de vitesses pilotée à 6 rapports :
  • Architecture interne de 2 arbres et un axe de marche arrière
  • Longueur : 390 mm
  • Masse : 50 kg (Avec huile et sans embrayage)
  • Capacité maxi de couple : 270 Nm
  • Butée d’embrayage concentrique hydraulique
  • 1ère, 3ème , 4ème , 5ème , 6ème synchronisation simple cône
  • 2ème synchronisation triple cône
