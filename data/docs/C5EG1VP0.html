IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Figure : c4bp1gkc
Dégarnir partiellement le passage de roue arrière (côté intervention).
Déposer l’écrou papillon ( 1) par l’intérieur du coffre.
Figure : c4bp1glc
Déposer :
  • L’agrafe 1/4 de tour (2)
  • Le feu réfléchissant supérieur (3)
Dégager le feu arrière ( 4).
Figure : c4bp1gmc
Déclipper les supports d’ampoules ( 5).
Déposer le feu arrière (4).
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
NOTA : Vérifier le fonctionnement des ampoules.
